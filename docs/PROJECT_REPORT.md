# Project Report

## 1. 프로젝트 개요

본 문서는 취업 포트폴리오 제출을 위해 프로젝트의 목적, 구현 과정, 기술적 판단, 결과 및 개선 방향을 정리한 보고서입니다.

## 2. 개발 배경

프로젝트를 시작한 이유와 해결하고자 한 문제를 작성합니다.

예시:

- 반복 작업을 자동화하기 위해 개발
- 데이터를 더 쉽게 확인하기 위해 시각화 도구 제작
- 하드웨어 설계 또는 알고리즘 동작을 검증하기 위해 구현
- 학습한 기술을 실제 결과물로 정리하기 위해 제작

## 3. 요구사항

| 구분 | 내용 |
| --- | --- |
| 입력 | 프로젝트에서 사용하는 입력 데이터 |
| 처리 | 핵심 로직 또는 연산 과정 |
| 출력 | 사용자에게 제공되는 결과 |
| 제약 | 실행 환경, 성능, 사용성 조건 |

## 4. 구현 과정

### 4.1 구조 설계

프로젝트를 기능별로 나누고, 코드와 문서를 분리하여 관리했습니다.

### 4.2 핵심 로직 구현

핵심 기능은 입력 검증, 데이터 처리, 결과 출력의 흐름으로 구성했습니다.

### 4.3 테스트 및 검증

정상 입력과 예외 입력을 나누어 실행 결과를 확인했습니다.

## 5. 기술적 고민

프로젝트에서 고민했던 설계 선택과 해결 과정을 작성합니다.

예시:

- 사용자가 쉽게 실행할 수 있도록 실행 명령을 단순화
- 결과를 재현할 수 있도록 입력 데이터와 실행 방법을 문서화
- 기능 추가를 고려해 폴더와 파일을 분리
