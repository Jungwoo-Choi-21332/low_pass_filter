# Project Report: Low Pass Filter Simulation

## 1. 프로젝트 개요

본 프로젝트는 RC Low Pass Filter의 동작 원리를 Python으로 구현하고 검증한 포트폴리오용 프로젝트입니다.  
입력 신호에 포함된 고주파 잡음이 저역통과 필터를 거치며 감쇠되는 과정을 수식 기반으로 시뮬레이션합니다.

## 2. 개발 배경

Low Pass Filter는 아날로그 회로, 센서 신호 처리, 오디오 처리, 통신 시스템에서 널리 사용되는 기본 필터입니다.  
회로 이론에서 배운 RC 필터의 수식을 실제 코드로 구현함으로써, 이론 이해와 소프트웨어 구현 능력을 함께 보여주기 위해 제작했습니다.

## 3. 요구사항

| 구분 | 내용 |
| --- | --- |
| 입력 | 저항값, 커패시터값, 샘플링 주파수, 시뮬레이션 시간 |
| 처리 | 차단 주파수 계산, 필터 계수 계산, 입력 신호 생성, 저역통과 필터 적용 |
| 출력 | 필터 적용 전/후 신호 데이터 CSV |
| 검증 | 단위 테스트로 계산식 및 필터 동작 확인 |

## 4. 구현 과정

### 4.1 필터 모델 설계

1차 RC 필터의 시정수 `tau = R * C`를 기반으로 차단 주파수와 이산 시간 필터 계수를 계산했습니다.

```text
fc = 1 / (2 * pi * R * C)
alpha = dt / (R * C + dt)
```

### 4.2 신호 생성

필터 효과를 확인하기 위해 저주파 기본 신호와 고주파 잡음이 섞인 입력을 생성했습니다.

```text
input = low_frequency_sine + high_frequency_noise
```

### 4.3 필터 적용

입력 샘플을 순차적으로 처리하는 1차 IIR 필터 구조를 사용했습니다.

```text
y[n] = y[n-1] + alpha * (x[n] - y[n-1])
```

이 방식은 RC 필터의 충전/방전 특성을 직관적으로 표현할 수 있고, 구현이 간결하며 실시간 처리 구조로 확장하기 쉽습니다.

## 5. 테스트 전략

`unittest`를 사용해 다음 항목을 검증했습니다.

- 차단 주파수 계산이 이론식과 일치하는지 확인
- 필터 계수 `alpha`가 0과 1 사이에 있는지 확인
- 일정한 입력 신호에 대해 출력이 입력값으로 수렴하는지 확인
- 고주파 성분이 포함된 신호에서 출력 변화가 완만해지는지 확인

## 6. 결과

기본 설정 `R = 1 kOhm`, `C = 1 uF`에서 차단 주파수는 약 `159.15 Hz`입니다.  
50 Hz 저주파 신호와 1000 Hz 고주파 잡음을 섞은 입력을 필터링하면, 고주파 변화가 완화된 출력 데이터를 얻을 수 있습니다.
