# Troubleshooting

프로젝트 진행 중 발생한 문제와 해결 과정을 기록하는 문서입니다.

## Issue 1. 실행 환경 차이

### Problem

개발 환경과 다른 PC에서 실행할 때 필요한 패키지나 도구가 누락될 수 있습니다.

### Cause

실행 방법과 의존성 정보가 명확히 정리되어 있지 않으면 재현성이 떨어집니다.

### Solution

- README에 실행 명령 추가
- 필요한 패키지 목록 작성
- OS 또는 도구 버전 명시

## Issue 2. 입력 데이터 오류

### Problem

잘못된 입력값이 들어오면 프로그램이 중단될 수 있습니다.

### Solution

- 입력값 검증 로직 추가
- 예외 발생 시 안내 메시지 출력
- 샘플 입력 데이터 제공
